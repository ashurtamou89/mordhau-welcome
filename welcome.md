## How to play & what to know

### Buy Menu — Keybind: B

This menu allows you to purchase skills, weapons, and vote on server settings.

### Purchase Skill Points

To purchase skill points, type in chat:

**!buy followed by the number of skill points**

**Example: !buy 100**

### Gambling

To gamble, type in chat:

**!gamble followed by the amount you wish to gamble**

**Example: !gamble 1000**

**Maximum: 999999**

### Change Server Settings

Default server settings can be changed when voting through the **Buy Menu (Keybind B).**

Examples:

- Difficulty
- Number of Horde AI
- 30 / 40 / 50 Waves
- Other available server settings

---

## Tips for New Players

### 1. Set up **ALL** skills right when you join.

### 2. Don't go over **255 skill points** or it resets to zero.

### 3. Refunding skills may reset your skill points to zero.

If this happens, simply buy more skill points.

### 4. Spawning more than **150 Horde enemies** may cause lag spikes.
